# 个人练习目录

后续用于保存小实验、示例 Prompt、API 调用、RAG PoC、Agent PoC 和运维场景实验。当前仅建立目录说明，实验实现状态为 `NOT_STARTED`。

## 练习约定

- 每个实验独立目录，记录目标、对应课程、环境、依赖版本、输入、运行方法、预期结果、实际结果与待验证项。
- 使用合成或经过核验的脱敏样本，保留数据来源、时间与单位说明。
- 暂时不放生产凭据、生产日志或敏感配置。仓库为公开 Fork，也不提交 Token、API Key、生产 IP、账号和密码。
- 凭据由运行环境提供，日志与报错输出检查脱敏。模型、依赖缓存、向量索引和大体积运行结果放到实验数据目录。
- 离线虚拟机实践中的引擎、模型、知识库、缓存、日志和相关数据统一放在 `/data`，日常运行账户为 `tailweb`。
- 记录失败和未运行的状态，示例存在不代表兼容当前 SDK 或模型。
- 运维工具练习先使用模拟或只读接口，修复执行纳入后续单独实验和人工审核。
- 完成实验后更新 [个人进度](../PROGRESS.md)，对应原理和结论记录到 [笔记](../notes/README.md)。
